# ❤️ Parents Anniversary Streamlit App

A small interactive Streamlit anniversary greeting for Mom & Dad.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

This project is ready for Streamlit Community Cloud.

1. Push the files to a GitHub repository.
2. Open Streamlit Community Cloud.
3. Select the GitHub repository and `app.py`.
4. Deploy.

## Customize

Edit `app.py` to change:
- Anniversary message
- Names
- Photos
- Anniversary date
- Colors and styling
